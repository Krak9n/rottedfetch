### My small Fetch program
![](https://github.com/Krak9n/rottedfetch/blob/rewrite/img/ex.png)

This is a small fetch written in Rust. 
**Shows:**
+ username <br />
+ os <br />
+ cpu <br />
+ gpu <br />
+ memory <br />
+ kernel <br />

### Installation
**From source**
Just clone it with git and run:
```
cargo install --path .
```

**Arch Linux**
Users of superior may download it from AUR.
```
yay -S rottedfetch
```

Happy Usage!
