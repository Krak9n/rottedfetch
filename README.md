Minimalistic system fetch. Uses predefined modules for displaying.  
  
### PREREQUISITES
---
+ cargo  
+ rustc  

### INSTALLATION
---
[![Packaging status](https://repology.org/badge/vertical-allrepos/rottedfetch.svg)](https://repology.org/project/rottedfetch/versions)  

---
#### Arch Linux  

Users of Arch Linux may download the package from the AUR [rottedfetch](https://aur.archlinux.org/packages/rottedfetch) repository.

#### Compiling from source  

Everyone else should clone the source code and compile with the Rust compiler.  

```bash
$ cd rottedfetch  
$ cargo install --path .  
```
